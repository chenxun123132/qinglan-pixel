# 青岚行 · 像素侠客录

一款 Q 版厚像素风格的自由探索 RPG 像素游戏。纯 HTML5 Canvas 实现，**单文件、零依赖、点开即玩**。

## 🎮 在线游玩

GitHub Pages 链接：**https://chenxun123132.github.io/qinglan-pixel/**

手机 / 电脑浏览器直接打开即可游玩，无需安装任何东西。

## 🕹 操作方式

| 平台 | 操作 |
| --- | --- |
| 电脑 | WASD / 方向键移动 · E 交互 · Esc 菜单 |
| 手机 | 屏幕左侧虚拟摇杆移动 · 右侧交互按钮 |

## 🎯 玩法内容

- **自由探索**：青岚村 → 苍莽原野 → 雷渊山巅 三张地图无缝切换
- **任务链**：采灵芝（3株）→ 斩妖猴（8只）→ 镇守雷渊（击败雷兽 Boss）
- **回合战斗**：攻击 / 技能（青锋斩、落雷符、御风诀）/ 道具 / 防御 / 逃跑，升级加点
- **角色养成**：等级、经验、属性点、装备（青锋剑 / 青岚袍 / 护身符）
- **系统**：商店买卖、铁匠强化兵器、背包管理、篝火回血、宝箱、本地自动存档

## 📁 项目结构

```
index.html    游戏全部内容（Canvas 引擎 + 全部逻辑 + 全部素材 Base64 内嵌）
```

- 全部美术素材为 AI 生成 Q 版厚像素画（圆润造型 / 粗轮廓 / 通透配色），已去除水印
- 所有图片以内嵌方式打包在 HTML 中，**无任何外部文件依赖**，GitHub Pages 打开不会出现素材加载失败
